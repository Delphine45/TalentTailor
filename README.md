# TalentTailor

A Figma plugin that rewrites your resume's experience bullets to match any
job description, using AI.

→ Install from the Figma Community: <coming soon, paste link after publish>

## How it works

1. Open the plugin on a frame containing your resume.
2. TalentTailor auto-detects your experience paragraphs and skips names,
   dates, skills, and contact info.
3. Paste the job description.
4. Click **Tailor paragraphs**. Each bullet is rewritten line-by-line.
5. Review side-by-side diffs with verbatim citations explaining what
   changed and why.
6. Apply individually or all at once.

## Setup (one-time)

You bring your own free Groq API key:

1. Sign up at [console.groq.com/keys](https://console.groq.com/keys) with
   Google or GitHub — no credit card.
2. Click **Create API Key** and copy it.
3. Paste it into the plugin's first-run setup screen.

Your key is stored only on your device via Figma's local plugin storage.

## Privacy

- No server. No tracking. No analytics.
- Your Groq API key is stored locally in Figma's `clientStorage` (per-device).
- Resume text and job descriptions are sent only to `api.groq.com` when
  you click "Tailor paragraphs". They are never persisted anywhere — including
  locally — beyond the immediate session.
